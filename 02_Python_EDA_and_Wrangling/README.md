# Module 2: Python Data Wrangling & Exploratory Data Analysis (EDA)

## Project Overview
This project covers programmatic web scraping, dynamic data cleaning, feature engineering, and data visualization using Python's core data science stack.

## Key Skills & Concepts
- **Data Scraping:** Extracting HTML table data dynamically via `pandas.read_html()`.
- **Data Cleaning:** Regex string manipulation, type casting, handling missing values (`NaN`).
- **Feature Engineering:** Creating workforce efficiency KPIs (`revenue_per_employee`).
- **Visualization:** Dual-panel exploratory plots built with `Seaborn` and `Matplotlib`.

## Files in Folder
- `exploratory_data_analysis.ipynb`: Executable notebook detailing the ETL process and EDA visuals.
