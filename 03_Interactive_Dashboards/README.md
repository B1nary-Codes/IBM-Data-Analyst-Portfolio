# Module 3: Interactive Business Intelligence Dashboards

## Project Overview
This module demonstrates visual data storytelling and interactive KPI dashboarding using Plotly Express and Graph Objects in Python. The objective is to translate raw transactional data into executive-ready interactive visual models for non-technical decision-makers.

## Key Skills & Concepts
- **Interactive Visualizations:** Hover tooltips, unified line charts, dynamic log-scale scatter plots, and multi-level hierarchy Sunburst diagrams.
- **KPI Tracking:** Aggregating transactional sales, profit margin calculations, and monthly trend forecasting.
- **Storytelling:** Multi-variable segmentation across product categories and global geographic regions.

## Business Key Performance Indicators
- **Revenue & Profit Margins:** Tracked revenue streams across categories to identify high-margin vs. volume-heavy products.
- **Geographic Segmentation:** Evaluated market penetration across regional territories to pinpoint underperforming markets.

- `interactive_dashboard.ipynb`: Executable Jupyter Notebook featuring fully interactive Plotly dashboards and metric summaries.
