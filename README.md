# Data Analytics Portfolio

Welcome to my data analytics portfolio. This repository showcases end-to-end data pipelines, relational database querying, statistical hypothesis testing, and data analytics across four structured modules. All code are from projects I worked on throughout the duration of CourseRA's IBM Data Analyst Professional Certification courses
